# A11yTO AI Workshop September 2026

This repository contains all the files needed to participate in the workshop.You can also find instructions on how to setup and start the project.

Note: There are two versions of the skill, `a11y-triage-v1` and `a11y-triage-v2`, v2 is a corrected version of the file, if you want to experiment with one with issues, try v1.

## Getting Started

Before everything, ensure you have the following:

- a GitHub account
- [Visual Studio Code](https://code.visualstudio.com/download) installed
- a local copy of this repository

### Downloading this repository

1. Open Visual Studio Code.
2. Go to the [repository page](https://github.com/reidmore-online/a11yTO-workshop-2026) and click on the green "Code" button.
3. Under the "Local" tab, find the "HTTPS" option under "Clone and copy the URL.
4. Go to Visual Studio Code, under "Explorer" select the option to "Clone Repository" and paste the URL into the text field that will appear at the top of the screen.
5. Select the location you copy the repository to (this is the folder that will be created on your computer).
6. Visual Studio Code should update and show you all the files.
